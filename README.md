# 7sProMax 3Dプリントケース

7sProMax（基板 v1.0）向けに、純正ケース図面と実物の基板・ボトムプレートの実測から設計した
3Dプリント用ケースです。

## 仕様

- 有線のみ / マイコンは ProMicro 系
- 傾斜なし（フラット）、左右連結スロットなし
- 片側3パーツ構成：トップフレーム（枠）／スイッチプレート（別体）／ボトムケース
- 白 FR4 ボトムプレートを底側の層として再利用
- 総高 16.1mm（純正側面図に一致）
- プリンタ想定：Bambu Lab A1 mini（180×180mm）

## ディレクトリ

- `design/` … パラメトリック CAD スクリプト（build123d）と生成 STL、設計メモ
  - `build_case.py` を実行すると STL を再生成できます
  - `DESIGN_NOTES.md` に設計判断・未確定事項を記載
  - STL は ASCII 形式で収録（バイナリ版と形状は同一）
- `template/` … 純正図面 PDF から抽出した平面テンプレ（DXF）と、実物のスキャン計測データ（CSV）・検証メモ

## 印刷の順番（推奨）

1. 試作片で実物との当たりを確認する
   - `trial_boss_*`（FR4 プレートのネジ穴位置合わせ、最優先）
   - `trial_stair_*`（階段境界の噛み合い）
   - `trial_corner_short`（パドル・TRRS・USB まわり）
2. 問題なければ全体（`top_frame_*` / `switch_plate_*` / `bottom_case_*`）を印刷する

## 状態

設計 v1。FR4 プレートの座標対応は試作片での実測補正が前提の未確定項目です（詳細は `design/DESIGN_NOTES.md` §9）。
