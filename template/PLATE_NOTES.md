## 座標系（プレート単体ローカル）

- 左右プレートごとに独立したローカル座標系。ケーステンプレ（DXF）の座標系とは**未接続**（後述）。
- 原点: 各プレートの**左下基準穴**（下辺の大穴のうち左側）の中心。L=L1、R=R1。
- X軸: 左下基準穴→右下基準穴（L2/R2）を結ぶ線。右方向が正。
- Y軸: X軸に直交し、プレート上辺方向が正。
- 単位 mm。穴IDは L1〜L9 / R1〜R10。

## スケール根拠と補正方法

主計測写真7312は真上からではなく若干の傾きがあるため、軸別に実物寸法で校正した。

- **縦（Y）**: 7313で定規目盛りの周期（10.03 px/mm）とマットマス目周期（9.95 px/mm）が一致することを確認したうえで、プレート奥行（上辺〜下辺）を実測 → **103.3mm**。7312上のプレート高さ px 数（輝度遷移で上下端を検出、L≈646px / R≈648px）から sy = **6.26 px/mm**。
- **横（X）**: 7314で定規周期（9.21 px/mm）とマス目周期（9.28 px/mm）から Rプレート幅 ≈ **174.9mm**。7312上の R 幅 px 数から sx = **6.18 px/mm**。
- マットマス目だけで測ると写真端部（マットの縁の目盛り帯）で数%ずれるため、マス目は補助に留め、スケールは実物（プレート自体の寸法）で確定した。
- 透視補正は「基準穴2点で X 軸を定義し、軸別スケールで換算」まで。ホモグラフィ等の全面補正はしていない（残差は誤差として明記）。

## 穴の検出と分類

- 白色度（min(B,G,R) が高くチャンネル差が小さい）でプレート領域を抽出し、内部の暗い円形ブロブを穴候補として検出。候補は全て拡大画像で目視確認した。
- 大/小の分類はブロブの等価直径（small ≤15.1px / big ≥19.9px と綺麗に分離）。直径の数値は写真からではなく**本人のノギス実測**（大 Ø2.8〜2.9 / 小 Ø1.7〜1.8）を採用し、CSVには中央値（2.85 / 1.75）を入れた。
- 結果: **全19穴 = L 9穴（大3・小6）/ R 10穴（大3・小7）**。
  - 基準穴間距離: **L = 102.6mm / R = 130.4mm**。
  - 穴の行（Y座標）は両プレートで揃っている: 上辺行 y≈91、上段 y≈74、中段 y≈55、大穴行 y≈35。左右で構造が共通していることも整合性の根拠。
- 照合結果:
  - 7313（L拡大）: L1→L9 の縦距離 35.0mm が完全一致。L1→L2 基線は 101.0〜101.8mm（本計測 102.6mm、差 約1%）。
  - 7319（R裏面）: 鏡像アフィンフィット（スケール 11.46 px/mm、等方）で R8 の残差 0.84mm、R9 は外挿位置のため 1〜2.6mm。

## 推定誤差

- 穴中心: 同一写真内の近傍では ±0.5mm 程度。プレート全域では **±1.5mm 以内**（スケール不確かさ±1%＋透視の残差）。
- 輪郭: ±0.5mm 程度。ただし L の左下角付近（写真で影・黒い物体が近い部分）は輪郭線が局所的に 2mm 程度内側に入っている箇所がある（plate_overlay.png 参照）。輪郭寸法の数値（L 141.1×103.1 / R 174.7×103.5）は外形の最大幅・奥行としては妥当。

## ネジ穴ではないもの（CSVに入れていない）

写真から読み取れたが、ネジ穴ではないため除外したもの:

- 金色の長穴（楕円スルーホール）: 各プレートの D/C 部品近傍に 2〜3個。電池回路（スライドスイッチ／コネクタ）用のメッキ長穴。
- 小さなメッキ穴（Ø約1mm）: D/C 近傍のペア、裏面の ZH1.5（2穴）・On スイッチ（3穴）フットプリント。7319 の検出ではこれらが暗ブロブとして出たが、拡大確認でフットプリントと判別し除外した。
- 「・・」状の極小ドット（シルク／ビア）: R 上面の D2/C2 近傍など。
- プレート裏面のコイン電池用半円切り欠き×2（上辺）。ネジ穴ではないが輪郭には影響する（上辺中央付近、裏面写真 7319/7320 で確認）。

未確認事項: 上記フットプリント類の正確な座標は今回起こしていない（ケース設計で必要になれば裏面写真から別途起こす）。

## ケーステンプレ（DXF）への接続について — 未実施

`7spromax_case_template_v2.dxf`（SCREW_HOLES レイヤー追加版）は**作らなかった**。理由:

- プレート単体のローカル座標は確定できたが、DXF のケース座標系への変換（平行移動＋回転）に使える共通の基準点が写真に写っていない。プレートはマット上に単体で置かれた写真しかなく、ケース図面・基板と重ねた状態での位置合わせ情報がない。
- 7319/7320 では基板のタブ（TRRS・マイコン）がプレート上辺の帯の上に少し見えるが、ここから推定できるのは上下方向の粗い関係だけで、±数mm の不確かさが残る。ネジ穴レイヤーとして DXF に入れる精度ではない。

**紙テンプレ確認で確定すべき点**（次の実作業）:

1. 1:1 紙テンプレ（DXF の OUTLINE/POCKET）に実物プレートを重ね、プレート外形とポケット輪郭の対応（回転・反転・平行移動）を確定する。
2. その状態で各ネジ穴中心をテンプレ上に転記し、本 CSV のローカル座標と突き合わせて変換式を決める。
3. あわせて本 CSV の穴位置が ±1.5mm の範囲で実物と合うか、基準穴間距離（L 102.6 / R 130.4mm）と行間隔（約 91 / 74 / 55 / 35mm）をノギスで再確認する。
4. 変換が確定したら、その時点で DXF に SCREW_HOLES レイヤーを追加する。
