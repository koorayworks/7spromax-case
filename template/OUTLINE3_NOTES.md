# OUTLINE3_NOTES — 階段輪郭の再構成（2026-11-04）

## なぜ作り直したか
`pcb_outline2` の階段帯はマット写真の局所エッジ探索（PCB_SCAN2_NOTES §6）で
作られており、基板表面の**段差状の溝（配線グルーブ）を実縁と誤認**した箇所が
多数ある。証拠：
- 実測ソケット中心（ドーム重心法）が輪郭の外側にはみ出す（short で4点、
  最大2.52mm）。基板の縁がソケット中心より外にあることはあり得ない。
- 輪郭が階段帯で最大約32mmも基板内側へ zigzag に食い込む（実物の縁は
  綺麗な矩形ステップ。階段が向かい合う実物写真でも段は矩形）。
このノイズ混じり輪郭を前提にしたため、側面バンド等の階段内壁が三角形に
膨らんだ（本人の目視指摘が発端）。

## 再構成方法（template/make_outline3.py）
階段帯を、信頼できるアンカーに整合する**矩形ステップ**として再構成した。
置換範囲は階段側の x∈[3.2, 113.7] の帯のみで、**非階段部は outline2 と
幾何学的に完全同一**（帯の外側の対称差面積 0.0000 mm² で検証済み）。

段（踏面）の x 区切りは公式図面テンプレートのケース外形の段位置
（≒ソケット列の中線 27.0/46.1/65.1/84.2）と一致させ、6段構成
（5列分＋背面寄りの踊り場）とした。各段の先端レベルは次の3アンカーの
突き合わせで決めた：

- A: outline2 の包絡極値・平坦ラン（段の中央〜端に残る実縁の断片）
- B: 端ソケット中心（ドーム重心実測）∓ ハーフ内一定マージン
  （short 8.63 = 列3/4/5 の実測マージン 8.56/8.65/8.68、
   long 9.05 = 列1〜4 の 9.19/9.27/8.94/8.78）
- D: 公式図面のケース外形段レベル ＋ 基板インセット一定値
  （short は +0.66〜0.73 が段3/4/5 で一致）

### タブ（short 列2）の判定
outline2 のトレースには先端 y=3.96 の平坦部があるが、これは**溝の誤認**と
判定した：
- ソケット S27 のドーム（中心 y=9.28、半径2.75）が基板内に収まる条件から
  先端は 6.53 以下でなければならない（3.96 自体はこの条件は満たす）。
- しかし段3〜5で成立するマージン一定モデル（B: 先端 = 9.28−8.63 = 0.65）と、
  公式図面のタブ段レベル 0.0 に対するインセット（D: 0.65、他段の
  インセット 0.66〜0.73 と一致）が独立に 0.65 を指す。
- リスクの非対称性：実物が 0.65 なのに 3.96 でモデル化すると基板が
  キャビティを約3.3mm突き破る（致命的）。逆は壁側の余裕が増えるだけ。
→ 先端 0.65 を採用。3.96 の平坦部はタブ上の溝とみなす（基板表面には
縁と平行な段差状の溝が写真でも確認できる）。

## 旧輪郭との差分
- 階段帯の面積：short +802.2 mm²（溝への食い込み＝谷を充填）、
  削り取りは 0.1 mm² のみ。long +202.1 mm²、同 0.1 mm²。
- 充填はステップ縁に接する連結成分だけに限定した。long の背面寄り
  (x≈103.4–114, y≈128–164.5) には階段縁から基板材で隔てられた
  **実在の矩形ノッチ**があり、これは埋めずに保存している
  （プローブ点 (108,145) 等で old/new とも非含有を確認）。
- 最大の食い込み除去：short 段3付近で outline2 の頂点が新輪郭の縁から
  26.98mm内側にあった箇所（頂点 (59.0, 41.2)、踏面レベル 10.25 から
  y方向では約31mmの食い込み）。long の最大は 11.64mm（(81.4, 155.3)）。
- outline2 の頂点で新輪郭の外に残った最大値：short 0.04mm /
  long 0.12mm（long タブ蹴上コーナーの1点 (46.09, 152.95)）。

## 検証
- 非階段部：outline2 と完全同一（対称差 0.0000 mm²）。
- プロファイル（帯内の min/max y）はステップ表と一致（蹴上ちょうどの
  x では両段を拾うため見かけの偏差が出るが形状は表どおり）。
- 全ソケット中心が新輪郭の内側。階段端ソケットの縁までの距離：
  short S25 10.22 / S27 8.63 / S26 8.58 / S19 8.65 / S13 8.67、
  long L31 9.19 / L03 9.05 / L33 9.02 / L32 8.93 / L21 4.08。
  ドーム半径 2.75 を引いた余裕は最小でも L21 の 1.33mm（正）。
- 実物写真との整合：階段が向かい合う写真（7373）で両半分とも矩形の
  段であり、zigzag は存在しない。タブは short で突出・long で後退し
  互いに噛み合う（図面のタブ段とも一致）。

## 既知の留保
- short 段1（前面コーナー歯）はアンカーAのみに基づく（Bと1.6mm乖離）。
  コーナー形状の近似であり、当たり確認は試作で行う。
- long 段5/6 の境（x=103.4）は short の蹴上位置に合わせた推定。
  実点列のばらつき（±0.8mm）の範囲内。

## 追記（v2.4.2、2026-11-04）: 非階段チェーンの直線化

§17.15 参照。本ノートの再構成（階段帯）はそのままに、残りの
非階段チェーン（端辺・前面辺・背面）も直線化した。手順は
make_outline3.py の後に次の 2 スクリプトを順に実行する形で、
どちらも決定的（再実行で CSV が完全一致する）。

1. `straighten_outline3.py` — 端辺・前面辺。
   - フィット規則: クリーンな直線ランの点で最小二乗し、真正点の
     外側への突出が 0.1mm 以下になるようクランプ
     （キャビティクリアランス ≥0.4mm を真正点に対して保証）。
   - short 端: y = 138.008 + 0.00387x（角 (3.60,138.02)／
     (113.07,138.45)）。short 前面: x = 3.003 + 0.00436y。
     long 端: y = 5.110 + 0.00012x。long 前面:
     x = 2.833 + 0.00263y（トレース自体が 1 直線）。
   - 除外（写真 7378／7379 で否定されたアーティファクト）:
     short 端の plateau（x 84〜98、y 140.5〜140.8）と MCU
     絡まり部、long 端のスパイク点 (85.71,4.14)。
   - 階段ストリップの対称差は 0.0000（§17.12 は無傷）。
2. `straighten_back.py` — 背面チェーン。
   - short 背面: x = 113.561 + 0.001748y、端×背面の角は
     (113.80,138.45)（両直線の交点）。旧ジグザグの最大偏差 1.31。
   - long 切り欠き壁: x = 103.431 + 0.000331y（クランプ
     shift 0.173）。long 背面プレーン: x = 113.175 + 0.002620y
     （タブ面＋本ランの 5 点がほぼ共線）。タブ A／TRRS タブ／
     y≈58 の段差は壁と背面プレーンの間の矩形として再構成し、
     TRRS タブ上面の落ち込み（最大 1.36）と段差部の偽スパイク
     （最大 1.75）を除去。端×背面の角は (113.19,5.12)。
   - 角の半径ファン（long y 164.45〜164.88、short 末端）は
     滑らかな半径のため保持。

最終 CSV: short 41 点／long 59 点。ソケット余裕は不変
（short 最悪 8.58=S26、long 4.08=L21）。辺ごとの偏差表と
検証値は DESIGN_NOTES §17.15 に集約した。
