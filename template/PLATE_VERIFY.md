## スケール（スキャン）

- 各スキャンとも、プレート脇の金属定規（モノタロウ 150mm）の 1mm 目盛り列を検出して fit。
  - scanL: **6.888 px/mm**、残差 rms 0.35px（≒0.05mm）、局所スケール（3分割）6.887／6.888／6.899 と均一（±0.15%）。
  - scanR: **6.888 px/mm**、残差 rms 0.35px、局所スケール 6.894／6.888／6.895 と均一。
- 公称 175 dpi = 6.890 px/mm とも 0.03% で一致。スキャンに実用上の歪みはないとして、単一スケール 6.888 px/mm を両プレートに採用。
- 穴中心は低閾値（グレー 80〜125）での暗ブロブ bbox 中心を複数閾値で平均して確定。閾値間のばらつきは大半の穴で ±1px（≒0.15mm）以内。円フィット・重心とも照合済み（印刷十字が穴内に見える穴では重心が十字側に引かれるため bbox を優先）。

## 各穴の変更量（v1 → v2、要旨）

- **Lプレート: X方向に系統的な大きな修正**（v1 が写真の透視で伸びていた）。
  - 最大変更: **L4 dx = −3.16mm**（109.1 → 105.94）。次いで L5 −2.72、L6 −2.53、L8 −2.42、L3 −2.22。
  - Y方向は ±0.8mm 以内（L4 +0.78 が最大）。
- **Rプレート: 変更は小さめ**。最大は基準定義に伴う R2 −1.89 のほか、R4 dx +1.20、R5 dy +1.14、R6 dx +0.80。
- 内部整合性: 行の Y 座標が両プレート・全穴で揃った（上辺行 y≈91.75、 上段 y≈73.90、中段 y≈55.2、大穴行 y≈35.1。v1 では ±0.5mm 散らばっていた）。実物プレート同士で構造が共通であることと符合し、v2 の精度の裏付けになっている。
- 推定誤差: 穴中心 **±0.2mm 程度**（L9 は ±0.25、R5 は ±0.3、後述）。

## 印刷十字と実穴中心のズレ（スキャン内直接計測）

印刷シートの円・十字が穴の開口内に透けて見えた穴だけを実測した（本人が TRRS 切り欠き基準で置いた配置でのズレ。v1 CSV 誤差と配置誤差の合算であり、内訳は分離できない）。ズレは「印刷十字中心 − 実穴中心」、プレートローカル座標（+x = 基準穴 1→2 方向、+y = 上辺方向）。

| 穴 | ズレ (dx, dy) mm | 備考 |
|---|---|---|
| L1 | 約 (+0.1, +0.3) | 十字が明瞭。ほぼ一致 |
| R1 | 約 (+0.3, +0.4) | 十字が明瞭 |
| R10 | 約 (+0.9, 0.0) | 十字が明瞭。今回の最大 |
| L5 | dx 約 +0.5（dy 未確認） | 十字の縦線のみ視認 |
| L8 | dx 約 +0.4（dy 未確認） | 十字の縦線のみ視認 |
| R6 | dx 約 +0.8（dy 未確認） | 縦線＋印刷円の弧を視認 |
| L9 | 約 (+0.3〜+0.6, +0.3〜+0.6) 推定 | 印刷円の弧が開口内左下に視認。中心は右上方向 |
| その他12穴（L2, L3, L4, L6, L7, R2, R3, R4, R5, R7, R8, R9） | **未確認** | 開口内に十字を確認できず（R4 は縦線らしき模様があるが定量化困難） |

実測できた範囲では、印刷十字は実穴より +x 側（最大 R10 の約0.9mm）に寄る傾向。配置が TRRS 切り欠き（上辺側）基準でも下辺・右側で 1mm 弱のズレが残る計算で、紙テンプレ照合で「合っているように見える」範囲でも実測ではこの程度のズレがある、という記録。

## 等倍印刷の成立について

- 今回のスキャンでは、シートの校正線（100mm）が定規の下に隠れて直接測れなかったため、**印刷自体の等倍性は未確認**。
- ただし印刷十字↔実穴のズレ（最大約0.9mm）は「v1座標の誤差＋配置のズレ」の合算であり、仮に印刷が完全等倍でも v1 誤差だけで同程度のズレが出る。等倍性を単独で切り分けたい場合は、シートの校正線を定規で実測するのが確実（印刷時に校正線 100mm を確認する手順どおり）。

## まだ確定できない項目

1. **印刷十字ズレの未確認12穴**（上表）。必要なら、十字が見えるよう穴内を明るく撮った接写が要る。ただし v2 座標はスキャンの実穴計測で確定済みで、この未確認は今後の紙テンプレ運用にのみ影響する。
2. **穴径**: スキャンの暗部径は壁面の影を含むため大穴で Ø3.2〜3.5mm 相当に膨らみ、実径（本人のノギス実測 大2.8〜2.9／小1.7〜1.8）とは一致しない。v2 でも直径はノギス実測値を据え置いた。
3. **ケース DXF 座標系への変換**: 今回も未実施（プレート単体ローカル座標の確定まで）。紙テンプレ（ケース側）に実物プレートを重ねた照合で変換を確定し、その時点で DXF に SCREW_HOLES レイヤーを追加する。
4. R5 の中心はタブ角の縁影の影響で不確かさがやや大きい（±0.3mm）。L9 は開口内の印刷円弧が bbox に触れるため ±0.25mm。

## 手順メモ（再現用）

1. スキャン2枚を 90° CW 回転して正立化（2048×1448）。
2. 定規の目盛り列（上辺の 1mm 目盛り）を輝度プロファイルで検出 → 歩行型インデックス付け＋線形 fit でスケール確定。
3. 穴候補を暗ブロブ検出（等価直径・円形度で選別、D/C 周辺の金色長穴・メッキ小穴・シルク印刷を位置で除外）→ 全19穴を同定。
4. 中心は低閾値 bbox の複数閾値平均＋円フィット／重心で照合。基準穴（L1/L2/R1/R2）は3手法一致を確認。
5. プレートローカル座標へ変換（原点=穴1、X軸=穴1→穴2、スケール 6.888 px/mm）。
6. 補助として写真 7339/7340 の目盛り fit で基準穴間のみ再計測し、スキャン値と突き合わせ。
