## 2. 鏡像ミスは無い（座標系の対応は正しい）

- 7375（表面）は鏡像なしでのみフィット成立、7374（裏面）は鏡像ありでのみ成立＝裏面視が鏡像になる物理と整合。
- つまり **DXF/設計フレーム＝基板表面視（組立時の向き）そのもので、左右・表裏の取り違えは無い**。「プレートが入らない」原因として鏡像・回転ミスは否定できる。

## 3. スイッチ中心のズレ（実基板 vs プレート穴＝DXF中心）

誘導再検出（フィット予測位置の窓内重心）による実測中心と DXF 中心の偏差:

- top/short（最も鮮明）: 25 点、**RMS 0.168mm、最大 0.355mm**、平均オフセット (+0.07, +0.01)mm、sd (0.13, 0.08)。**全体の平行移動・回転・スケール異常なし**。
- top/long・back/long は写真のブレ/反射で重心が偏るが、ICP inlier ベースでは RMS 0.19〜0.20mm。
- 生成 STL の実測でも裏付け: switch_plate_long.stl を z=0.75 で断面計測 → 穴 33/33 件、中心オフセット dx −0.024±0.153 / dy +0.016±0.119mm、穴寸法 ≈14.95mm。switch_plate_short.stl は z=3.0 で計測 → 27/27 件、dx −0.022±0.139（dy は階段ノッチ近傍の外れ値で sd が膨らむが中央値は正常）。

**結論: 穴位置の誤差は最大でも 0.35mm 級で、14.95mm 角穴に対して原因になり得ない。**

## 4. 「スイッチがプレートの穴に入らない」最有力原因 = 穴サイズ

- 現行プレート穴は図面（アルミトップケースのウェル開口＝クリアランス開口）の **14.95×14.95mm** をそのまま流用している。
- MX スイッチのプレートパチ留め標準は **14.0×14.0mm（板厚 1.5mm）**。14.95mm では片側 0.475mm のガタがあり、**スイッチはプレートに保持されず抜け落ちる/留まらない**。本人の訴え（プレート自体はフレームに入るが、スイッチが穴に入らない/留まらない）と整合する。
- 対処（設計変更は親側判断）: プレート穴を 14.0mm 角（FDM では +0.1〜0.2mm の印刷補正を見込むのが定石）へ変更。位置は現行 DXF 中心のままでよい。

### 付帯発見: switch_plate_short.stl の異常

design/ の switch_plate_short.stl は板本体が **z≈2.13〜3.65 に浮いた**状態で、z=0 に薄い別ソリッド（底面のみ 1512 頂点）が残っている（long 側は z=0..1.5 の正常な単一スラブ）。印刷に使ったファイルがこの STL なら、スライサでの配置/サポートに影響した可能性がある。要確認。

## 5. 階段の確定寸法とキャビティ干渉

DXF 外形の階段レベル（end 位置）: short は y=0 / 9.5 / 14.5 / 24.0、long は y=153.42 / 162.92 / 167.92 / 177.42。
現行キャビティは一律 inset 2.6（short は +2.6、long は −2.6 した位置が壁）。

マット写真（7378/7379）から DXF 予測位置まわりの局所エッジ探索（色差 R−B の勾配最大）で実基板の end プロファイルを実測した結果、**基板の歯とケース外形の歯は位相（歯の並び位置・幅）が一致しない**。基板の歯は相手側基板と噛み合う形状であり、この半分のケース外形のオフセット複製ではないため、一律 inset ではクリアランスが保存されない。

階段クリアランス（キャビティ壁 − 実基板 end、正=隙間、負=干渉）:

- **short**: 歯先の並ぶ帯で −0.7〜−1.9mm の干渉が繰り返し出現（x=32〜44 で −0.66〜−1.85、x=52/56 で −2.39/−3.57 ※ライザ近傍は位相差で値が膨らむ）。隙間が +0.25 しかない点（x=104）もある。ポリゴン距離法では最小 −2.36mm、p10 −1.77mm。
- **long**: x=72〜84 で −0.82〜−2.07mm、x=28 で −2.56、x=48 で −4.72（ライザ近傍）など。ポリゴン距離法では最小 −2.33mm、p10 −1.56mm。
- 両半分とも、階段境界サンプルの約半数がクリアランス ≤0。**「輪郭は合って見えるのに実際には入らない」（7376 写真）ことと完全に整合する。**

通常の縁（直線部）の実測マージン（基板縁→ケース外形）とクリアランス（マージン−2.6）:

| 部位 | マージン実測 | 現行クリアランス |
|---|---|---|
| 前面（x≈0 側） | 約 3.0〜3.5mm（旧解析）＋今回の局所測定 3.3〜6.3（ばらつき大） | +0.4〜+0.9mm 程度 |
| 背面（ポケット間） | 約 2.9〜3.9mm | +0.3〜+1.3mm |
| 外側端 short | 旧輪郭ベースで約 3.3〜4.0mm | +0.7〜+1.4mm |
| 外側端 long | 今回実測 end y≈1.2〜3.3mm | **−1.4〜+0.7mm（壁に接する/食い込む箇所あり）** |

印刷収縮: FDM（PLA/PETG）の収縮 0.3〜0.6% をキャビティ長 110〜172mm に適用すると壁は片側さらに約 0.17〜0.5mm 内側へ寄る。上記の階段干渉は収縮なしでも発生し、直線部も収縮込みでは実質 0〜0.5mm になる。

### 推奨クリアランス（FDM 前提）

- **直線部: 片側 0.5mm 以上を公称で確保**（収縮 0.3〜0.6%＋押出幅のばらつき±0.1〜0.2mm を吸収し、最悪でも 0.2mm 程度残る計算）。
- **階段部: ケース外形の inset ではなく、実測した基板外形（pcb_outline2）から外側へ 0.5mm オフセットした形状をキャビティ壁にすること**。歯の位相が違う以上、外形 inset では原理的に合わない。

## 7. 基板のネジ穴（新設: pcb_screw_holes.csv）

スイッチ中心から 8.5mm 以上離れた円形検出を複数写真で照合した候補を `template/pcb_screw_holes.csv` に収録（信頼度・推定径つき）。要点:

- **確度の高い基板ネジ穴は前面帯（case x≈9〜30）とコーナーに集中し、Ø4mm 級**。HIGH: long (9.08, 110.36) Ø≈3.7、long (9.85, 136.01) Ø≈3.9、short (16.49, 135.16) Ø≈4.5。MEDIUM: short (29.03, 129.78)、(52.62, 133.69)、(29.22, 105.26)、long (14.68, 3.31)。
- **FR4 穴（plate_holes_v2.csv、全19穴）との対応は無い**: PLATE_TF（build_case.py の推定変換）でケース座標化した FR4 穴に対し、基板穴候補の最寄り距離は最小でも 5.0mm（大半は 10mm 以上）。注釈画像でも FR4 位置（黄円）は基板の実在しない場所に落ちる。
- → **build_case.py の「基板深部の FR4 穴には基板にも取付穴がある（hang）」という前提は誤り**。原設計でネジは基板を貫通していない（FR4 プレートだけを止めている）。白 FR4 を無くす場合は、ボス基準を上記の基板ネジ穴（前面帯＋コーナー）に移す必要がある。
- 背面帯の小径穴（Ø1.4〜2.1）が両半分にある（short (107.06, 64.07)、(107.43, 117.38)／long (110.15, 28.31)、(101.10, 83.43)、(107.23, 83.58)）。タブ/部品関連の可能性があり、ネジ穴かは未確定。
