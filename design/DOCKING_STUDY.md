# 7sProMax 左右ドッキング（一体型風連結）実現可能性検討

2026-11-04。本人選択「一体型風の連結を検討して」を受けた検討のみの資料。
**形状変更はしていない。** 実装は本人承認後に別途行う。

前提: 配置は公式図面レイアウト（両半分とも反転・鏡像なし、背面が揃う、
相対 x オフセット 0）。long を原点に固定し、short を相対 dy だけ
y 方向へ寄せる。short=左手・long=右手。
方法: build_case.py のケース外形ポリゴン（現行 v2.3 STL の平面外形と一致）
での干渉/距離の二分探索、0.1mm 刻みスライスでのフェイスプロファイル解析、
現行 STL の水平断面へのマーチングによるフェイス裏の材料深さ実測。

## 1. 突き合わせの幾何（現行形状同士）

- 公式レイアウト（dy=183.414）での最接近は **16.40mm**（x=45.84 の踏面どうし）。
- そのまま y 方向へ寄せると **dy=167.019 で接触**（公式レイアウトから 16.40mm 寄せた位置）。
- 接触するのは **x∈[43.35, 45.84]、幅 2.49mm の踏面どうしの面接触が1か所だけ**
（short の最深歯フェイス y=−2.05 × long の踏面フェイス y=164.97）。
- 第2の接近点は x∈[81.55, 83.95]（long の最深歯 177.22 × short の谷 12.22）で、
接触時点でも隙間 2.02mm。
- 接触位置での継ぎ目の隙間分布（x スライス）: **平均 9.31mm、中央値 9.63mm、最大 15.19mm**。
隙間 ≤0.3mm の区間は継ぎ目延長の **2.3%** のみ、≤3.0mm でも 12.3%。

→ 現行形状同士は「1点で触れて他は大きく開く」。面で合う形にはなっていない。

## 2. 位相の相性

- **基板（pcb_outline3）同士は完全な相補（テッセレーション）**。基板同士の接触は
dy=152.08 で、主階段 x=26.6〜84.4 の全域で必要 dy が 151.97〜152.08
（ばらつき 0.11mm）に揃う。本家の全体寸法 296.7mm は、この完全噛み合い
（基板だけのスパン 290.28mm）に両端のケース壁 約6.4mm を足した値と整合する。
つまり本家は「階段が全面で噛み合う」前提の寸法。
- **ケース外形では相補性が壊れている**。主因は蹴上（ライザ）フェイスの x 位置:
量子化＋壁厚確保で両半分とも歯が x 方向に太った。基板では共有境界だった
x=46.2 に対し、short の歯は x=49.05 まで、long の歯は x=43.35 から始まり、
**歯同士が x で 5.70mm 重なる**。重なり区間では歯×歯の対向になり、
必要 dy が約 +9.5mm 跳ね上がる。
接触 dy の内訳: 152.08（基板の噛み合い）＋ 2×2.7（踏面の張り出し）
＋ 9.54（蹴上の重なり）＝ 167.02。
- 踏面の張り出し（基板→ケースフェイス）も不均一: short 平均 4.00（最大 13.05）、
long 平均 4.30（最大 12.24）。棚状の厚肉部だけを壁 1.2mm まで削っても
dy_c は 164.80 止まり（バインディングは蹴上重なりの x≈45.8）。
基板の単純オフセット（バッファ）でも同様で、壁 0.8 まで薄くしても 164.20。
→ 問題は「厚さ」ではなく「蹴上の x 位相」。
- **x 方向へずらす案**: dy_c(dx) を dx=−19.05〜+19.05 で走査。最良は
dx≈−9.5（−5.8 でも同値）で dy_c=164.80、現行比 −2.2mm のみ。
代償として背面の揃いが |dx| だけ崩れ、キー列の見た目にも段差が出る。
位相ずれの根本解決にはならない。

## 3. ドッキング時の全体寸法（y 方向スパン、本家キット 296.7mm と比較）

| 配置 | dy | 全体スパン | 本家との差 |

| 公式図面レイアウト | 183.414 | 326.77 | +30.07 |
| 現行形状・接触（dx=0） | 167.019 | 310.38 | +13.68 |
| 現行形状・x シフト最良（dx=−9.5） | 164.80 | 308.16 | +11.46 |
| 案2（壁 2.2） | 157.78 | 301.14 | +4.44 |
| 案2（壁 1.2） | 155.78 | 299.14 | +2.44 |

x 方向（奥行）は 114.29mm で本家 114.2 とほぼ一致（+0.09）。

## 4. 磁石ポケットの肉厚実測（階段フェイス裏、組立 z で水平断面を実測）

| 部位 | z | フェイス裏の材料深さ |
|---|---:|---:|
| トレイ床 | 1.25 | 14 以上（床は全面ソリッド。ただしトレイの壁高は 2.5 しかない） |
| バンド薄壁部（光漏れ帯） | 3.3 | 1.1〜1.2（BAND_T=1.2 そのもの） |
| バンドレッジ帯 | 4.7〜5.4 | 4.1〜4.2（ただし帯の高さは 1.3 しかない） |
| フレーム下帯 | 6.5〜9.0 | 2.1〜2.2 |
| フレーム | 10.0 | 1.9〜2.0 |
| フレームリム帯 | 11.4〜15.0 | 1.7〜1.8（背面側 x=100 では z≥11.4 で外形まで届かない箇所あり） |

結論:

- **Nape 実績の Ø6 円盤磁石（水平軸）は現行の階段壁のどこにも入らない。**
Ø6 は高さ 6mm 級＋深さ（磁石厚 2＋底 1）=3mm 級が要るが、深さ 2.2 ある
フレーム下帯は高さ約 4.3（z 5.7〜10）しかなく、リム帯は深さ 1.7 しかない。
- 使えるのは **バーマグネット 12×3×2** をフレーム下帯（z 6.0〜9.5）に
「片側 1.0mm 突出＋相手側に段付き受け」で入れる方式。壁 2.2 に対し
ポケット深さ 1.0 で底 1.2、受け側は段差 0.8 で底 1.4 を確保できる。
突出したバーが相手の受けに入るため、位置決めの補助にもなる。
- 候補位置（踏面幅 18mm 以上＋肉厚 2.1〜2.2 を実測で確認済み）:
- ペア A: x=36（short 歯フェイス −2.05 ／ long 谷フェイス 155.43）
- ペア B: x=55（long 歯フェイス 164.97 ／ short 谷フェイス 7.54）
- ペア C: x≈100（背面側の直線フェイス対 177.22 ／ 21.76）
各対で突出側を交互にする。ペア C はフレームのウェル（スイッチ開口）との
距離を実装時に断面で再確認し、x=90〜105 で微調整する。

## 5. 連結方式の案

### 案1: 磁石のみ（現行外形のまま、接触位置で保持）

- 変更: フレームへの磁石ポケット×3対のみ。外形変更なし。
- 問題: 接触が幅 2.5mm の1か所だけで継ぎ目は平均 9.3mm 開く（§1）。
磁石で引き寄せても見た目は一体にならず、保持点が実質1か所では
回転方向の位置も決まらない。**不採用。**

### 案2: 継ぎ目整形（共有シームカーブ）＋バーマグネット

- 両半分の階段フェイスを、基板のテッセレーションから作る **1本の共有
シームカーブ** 上に再設計する。踏面は「基板＋0.5 キャビティ＋壁 2.2」
＝張り出し 2.7 で統一し、蹴上の x は基板の共有境界に戻す（歯を太らせない）。
背面側の直線区間（x≳87）はフレームのウェル制約があるため long フェイスを
現行のまま残し、short 側を最大 2.0mm 延長して合わせる。
- 到達値: **dy*=157.78、全体 301.14mm**（壁を 1.2 に詰めれば dy* 155.78／299.14）。
継ぎ目の隙間は主階段（x 26.6〜84.4）で **0.30mm**、両端のランアウトでも
最大約 1.4mm。フェイスの移動量は平均 1.3〜1.6mm、最大は long の棚部
9.5mm（x 43〜46、現行は肉厚 11.7 ある場所を 2.7 に戻す）。
- 変更パーツ: 両半分の tray / band / frame の **階段帯のみ**。外形の他の辺、
背面、USB/TRRS 開口、パドルスロットは不変。試作片（trial_stair_band、
trial_corner_*）は作り直しになる。
- 単体使用への影響: なし（中央側フェイスの形が変わるだけ。棚が消える分、
わずかに小さくなる）。
- 手間: build_case.py の quantize_stair をシームカーブ生成に置き換える
中規模の改修＋check_v21 全項目の再検証。印刷・組立は従来どおり。
- 一体感: 最も高い。階段が全面で互い違いに噛み合い、隙間 0.3mm の継ぎ目が
1本の線になる。噛み合い自体が x/y 両方向の位置決めになり、磁石3対は
引き離し方向の保持専任で済む。

### 案3: 下敷き連結プレート

- 両半分がはまる浅いポケット（深さ 1.5）付きプレート
（約 314×118×3.5、接触 dy 配置）＋必要ならポケット内の磁石/ピン。
**ケース変更ゼロ。**
- 一体運用（位置決め・持ち運び）はできるが、継ぎ目の開き（平均 9.3mm）は
そのまま残り、見た目の一体感は限定的。全体が実質 +2mm ほど高くなる。
プレートは A1 mini（180×180）に入らないため 2〜3 分割印刷＋接合が要る。
- 単体使用はプレートから外すだけ（影響なし）。案2 の整形後に組み合わせれば
位置決めは完全になる。**ケース改修を避けたい場合の次善策。**

### 案4: 連結タブ（トレイ床面レベル＋垂直軸 Ø6 磁石）

- トレイから舌状タブを継ぎ目へ伸ばし、相手側の受け溝と組み合わせ、
タブ内に Nape 式六角穴の Ø6 磁石（垂直軸）で留める。トレイ床は全面
ソリッドなので磁石の肉厚は十分ある。
- ただし現行の隙間（タブ位置で 9.6〜12.2mm）を渡る舌は 16〜19mm 級になり、
薄く（≤2.5）細くて折れやすい。単体使用時に中央側へ舌が飛び出すのも難。
継ぎ目上部の開きも残る。**案2 に劣る。**

## 6. 推奨と実装時の注意

**推奨は案2（継ぎ目整形＋バーマグネット3対）。** 一体感・位置決め・
全体寸法（本家 +4.4mm）の全てで唯一成立する案。磁石だけ（案1）では
幾何が伴わず、下敷き（案3）は見た目が届かない。

実装時の注意:

1. シームカーブの制約は基板だけでなく **フレームのウェル（スイッチ開口）
までの距離**も取り込むこと（背面側 x=100 で現行フェイス裏は 2.1mm。
§5 案2 の背面区間の扱いはこのため）。
2. 磁石ペア C は x=90〜105 の範囲でウェルとの距離を断面確認して決める。
3. 整形後は check_v21 全項目（階段クリアランス、フレーム下降スイープ、
パーツ間干渉）の再実行と、trial_stair_band の実物当て確認が前提。
4. パドル・背面ネジ・TRRS は背面側（x≈114 の壁）で、継ぎ目（y 向きフェイス）
と干渉しないことを確認済み（配置・寸法とも独立）。
